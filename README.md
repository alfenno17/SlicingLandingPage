# The Swaha Signatures - Landing Page Project

Projek ini dibuat sebagai latihan slicing landing page dari alamaya untuk persiapan prakerin, dengan mempertahankan tools bantuan yang digunakan (Figma TeleportHQ, Hermes AI Agent, Gemini Pro) dan menghasilkan kode web bersih berbasis Bootstrap 5.

---

## 🛠️ Tech Stack & Tools
- **HTML5 & CSS3** (Custom Styling & Layout)
- **Bootstrap 5 & Bootstrap Icons** (Responsive Grid & UI Components)
- **JavaScript (ES6)** (Interactive loading screen & DOM behavior)
- **Figma (TeleportHQ Plugin)** (Desain UI / Slicing awal)
- **Hermes AI Agent** (Autonomous AI Assistant untuk arsitektur, koding, dan debugging)
- **Gemini Pro** (Analisis visual & bantuan penalaran desain)

---

## ✨ Fitur & Alur Halaman
1. **Loading Screen**: Animasi transisi pemuatan halaman awal menggunakan GIF kustom yang tampil fullscreen.
2. **Hero Section**: Layout asimetris presisi tinggi dengan tipografi tebal (`YOUR VERY HOME`), efek blur latar belakang, badge harga, dan tombol *Book Your Stay*.
3. **The Swaha Story**: Section pengenalan resort dengan aksen catatan tempel *"Good stays, Better Memories"* dan galeri foto sudut resort.
4. **Rooms Section**: Menampilkan pilihan tipe kamar (Deluxe, Grand Deluxe, Junior Suite) lengkap dengan harga dan tombol aksi.
5. **Dining & Wellness**: Fasilitas resort termasuk *The Restaurant*, *Crux Bar*, *Rooftop Infinity Pool*, dan *Fitness Center*.
6. **Location & Neighborhood**: Informasi jarak strategis ke pantai dan *beach club* populer di Berawa.
7. **Special Promo & Footer**: Penawaran spesial langsung dan footer lengkap berisi kontak, sosial media, serta *newsletter subscription*.

## 🚀 Cara Menjalankan Projek
1. Pastikan Anda memiliki browser modern (Chrome, Safari, Firefox).
2. Clone atau buka folder projek ini di editor kode (seperti VS Code).
3. Jalankan menggunakan **Live Server** extension di VS Code, atau buka langsung file `index.html` di browser.
